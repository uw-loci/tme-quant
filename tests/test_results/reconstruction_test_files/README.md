# MATLAB wrapping references

These ten portable NPZ files were generated by the original CurveLab MATLAB
`fdct_wrapping`, `ifdct_wrapping`, and `fdct_wrapping_window` routines (Laurent
Demanet, 2004), as distributed with CT-FIRE 3.0. They contain real inputs,
complex forward coefficients (`C`), thresholded/scale-selected coefficients
(`Ct`), filtered inverse results, and full inverse results. They load with
`numpy.load(..., allow_pickle=False)` and need no MATLAB installation or
microscopy files to test.

`manifest.json` records the MATLAB version, source SHA-256 checksums, fixture
checksums, and case descriptions. Shapes include square, rectangular, odd, and
non-power-of-two dimensions; coarse angular counts include 8, 16, and 32.

To regenerate, put `CurveLab-2.1.2/fdct_wrapping_matlab` first on the MATLAB path
and run `generate_matlab.m`. Then, from the repository root:

```bash
.venv/bin/python tests/test_results/reconstruction_test_files/pack_references.py \
  --source-dir /path/to/CurveLab-2.1.2/fdct_wrapping_matlab
```

The intermediate `.mat` files are ignored; commit the NPZ files and updated
manifest together. Regeneration uses the MATLAB source, never the Python port.

`tests/test_matlab_wrapping.py` checks every forward coefficient's shape and
value, inverse reconstruction from MATLAB's filtered coefficients, and full
round trips. Seven cases also exercise `ct_reconstruction` at its fixed
16-angle setting. Small fixtures retain `min(3, number_of_scales-1)` scales to
keep the selected scales valid in MATLAB.

The symmetric impulse case has coefficients tied at the 20% cutoff. FFT
rounding changes which tied coefficients survive strict thresholding; the
observed filtered reconstruction difference is about `4.23e-5`. Its forward,
filtered inverse, and full round-trip references are tested independently,
while `ct_reconstruction` integration uses the seven nondegenerate/zero cases.
The other two fixtures use 8/32 angles, which CT-FIRE reconstruction does not
select. There are no skip or xfail markers for these new references.
